# Universidade Explorer

Mini app em React Native (Expo) para explorar cursos e estudantes de uma universidade.

## Funcionalidades

- **HomeScreen** – lista de cursos (Engenharia, Informática, Medicina).
- **CourseScreen** – nome e descrição do curso, com botão "Ver Estudantes".
- **StudentsScreen** – lista de estudantes do curso.
- **ProfileScreen** – perfil do estudante, recebido como parâmetro.
- Bottom Tab Navigation entre "Home" e "Sobre".
- Botão "Voltar" em cada tela.

## Tecnologias

- Expo
- React Navigation (native stack + bottom tabs)
- TypeScript

## Como executar

```bash
npm install
npx expo start
```

Depois é só ler o QR code com a app Expo Go.
